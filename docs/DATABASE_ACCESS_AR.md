# الدخول إلى قاعدة بيانات amrbit

النظام المحلي يستخدم SQLite. القاعدة ملف في:

`C:\xampp\htdocs\fieldflow-next\database\database.sqlite`

لا يوجد اسم مستخدم أو كلمة مرور لمحرك SQLite هنا. حساب amr وكلمة المرور 123456 لتسجيل الدخول إلى التطبيق، وليس لفتح ملف القاعدة. phpMyAdmin الموجود في XAMPP مخصص لـMySQL/MariaDB ولا يفتح هذا الملف.

## فتحها بواجهة رسومية

1. حمّل DB Browser for SQLite من الموقع الرسمي https://sqlitebrowser.org/dl/ واختر نسخة Windows المناسبة، أو نسخة zip دون تثبيت.
2. افتح البرنامج ثم Open Database وحدد الملف السابق.
3. افتح تبويب Browse Data، ثم اختر users من قائمة Table.
4. ابحث عن الحساب برقم id أو اسم username. غيّر name للاسم الظاهر، أو username لاسم الدخول. اسم الدخول حرفان إلى 40 من الحروف الإنجليزية الصغيرة والأرقام والنقطة والشرطة والشرطة السفلية، ويجب أن يكون فريدًا.
5. اضغط Write Changes لحفظ تعديلك، ثم حدّث صفحة النظام.

جدول users يحفظ الهوية واسم الدخول. جدول company_user يحفظ الشركة والدور وحالة الدخول وصلاحيات البيع والتحصيل. جدول representative_areas يحفظ مناطق المندوب عند تقييد التغطية. لا تغيّر أرقام id لتغيير الأسماء؛ المستندات والرحلات مرتبطة بهذه الأرقام.

الموقع الرسمي للبرنامج يوضح دعمه لفتح وتعديل ملفات SQLite: https://sqlitebrowser.org/ . يُفضّل حفظ نسخة احتياطية قبل تعديل القاعدة مباشرة، باستخدام scripts/backup.ps1.

## تغيير كلمة المرور

خانة password تحتوي تجزئة آمنة Hash. كتابة 123456 مباشرة فيها ستمنع الدخول. لتعديل المندوب أو المحاسب من التطبيق: ادخل بحساب amr، ثم الفريق ← تعديل وصلاحيات، واكتب كلمة المرور الجديدة وتأكيدها مع سبب التعديل. التطبيق يحفظ التجزئة تلقائيًا.

حساب المدير نفسه محمي من شاشة إدارة أعضاء الفريق. لتغييره محليًا عبر Laravel افتح PowerShell ونفذ:

```powershell
cd C:\xampp\htdocs\fieldflow-next
.\scripts\php.ps1 artisan tinker
```

ثم داخل Tinker، هذا مثال للحساب رقم 1:

```php
$user = App\Models\User::findOrFail(1);
$user->username = 'amr';
$user->password = '123456';
$user->save();
exit
```

غيّر الرقم واسم الدخول وكلمة المرور وفق حسابك. Laravel يجري التجزئة تلقائيًا عند إسناد password إلى النموذج. تغيير القاعدة مباشرة يتجاوز التحقق وسجل مراجعة إجراءات الواجهة؛ استخدم إدارة الفريق عندما يكون الحساب قابلًا للتعديل منها.
