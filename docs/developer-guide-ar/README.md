# دليل فهم وتعديل amrbit

مراجعة المصدر وقاعدة العرض بتاريخ **25 أكتوبر 2026**. هذا الدليل يشرح **ما هو موجود فعلًا** في النسخة المحلية، ويفصل بينه وبين الأفكار المستقبلية. لم تُغيّر البيانات أو وظائف النظام أثناء إعداده.

## ابدأ من هنا

المشروع الحالي الذي يظهر على المنفذ 8090 هو:

```text
C:\xampp\htdocs\fieldflow-next
```

المجلد `C:\xampp\htdocs\fieldflow` مشروع سابق، ويحتوي أيضًا على نسخة PHP المستقلة التي تستخدمها النسخة الجديدة. انتبه عند فتح المحرر: تعديل المشروع القديم لن يغيّر صفحات الجديد.

| المعلومة | القيمة المتحققة |
|---|---|
| اسم المنتج الظاهر | amrbit |
| Laravel المثبت بحسب composer.lock | v13.35.0 |
| Sanctum المثبت | v4.3.3 |
| PHP المستقل الذي فُحص | 8.4.26 |
| مسار PHP | C:\xampp\htdocs\fieldflow\.runtime\php84\php.exe |
| قاعدة البيانات | SQLite، ملف محلي، وليست MySQL |
| ملف قاعدة البيانات | C:\xampp\htdocs\fieldflow-next\database\database.sqlite |
| عدد الجداول وقت الفحص | 35 جدولًا، منها جداول Laravel المساعدة |
| أمثلة حجم البيانات وقت الفحص | شركتان، 15 حسابًا، 16 عضوية، 48 عميلًا، 13 مركبة |
| الواجهة | Blade + JavaScript عادي + CSS + Leaflet؛ ليست React أو Vue |
| تسجيل دخول المتصفح | Session واسم مستخدم |
| دخول الأجهزة عبر API | Sanctum Bearer token |

الأعداد لقطة فحص، وتتغير باستخدام النظام. بيانات العرض مصطنعة. اسم الشركة الأولى تغير إلى «شركة رواد الورقيات»، لكن بعض أسماء الأصناف وتصنيف الصناعة القديم ما زال من بيانات توزيع المياه التجريبية؛ هذا ليس قاعدة ثابتة لقطاع النظام.

## مسار القراءة

للقراءة ككتاب واحد بتنسيق عربي فاتح: [افتح نسخة HTML](AMRBIT-HANDBOOK-AR.html). تعمل محليًا دون تحميل مكتبات من الإنترنت، وتدعم البحث العادي في المتصفح والطباعة. ملفات الفصول أدناه مناسبة للتعديل والرجوع إلى المصدر.

1. [01 — الهيكل ومسار الطلب وتسجيل الدخول](01-ARCHITECTURE-AUTH.md): ما معنى app و Controller و Provider و Model وكيف تتواصل.
2. [02 — جميع الصفحات والمسارات والإجراءات](02-PAGES-ROUTES.md): من كل شاشة إلى ملفاتها والجداول المستخدمة.
3. [03 — شرح دوال PHP الخاصة بالمشروع](03-PHP-FUNCTIONS.md): Controllers و Services و Models و Middleware و Enums و Policy.
4. [04 — الواجهات ودوال JavaScript و CSS](04-FRONTEND.md): رسم الأقسام والنماذج والضغطات وطلبات الشبكة.
5. [05 — قاعدة البيانات وفتحها والعلاقات](05-DATABASE.md): فتح SQLite، الحسابات، الاستعلامات، فهم المال والمخزون.
6. [06 — كيف تعدّل وتفحص وتشغّل](06-EDITING.md): وصفات عملية وتتبّع الأخطاء وحدود النسخة.
7. [07 — قاموس كل جدول وكل عمود والفهارس](07-SCHEMA.md): مستخرج من القاعدة الفعلية، وليس تصورًا نظريًا.
8. [08 — فهرس ملفات المصدر والدوال بأرقام الأسطر](08-SOURCE-INDEX.md): للعثور السريع على التعريف، مع فهرس الاختبارات.

اقرأ 01 ثم 02 ثم 05 أولًا. بعد ذلك اختر عملية واحدة، مثل تعديل هاتف عميل، واتبعها في 03 و 04. لا تحتاج حفظ كل أسماء الدوال قبل أول تعديل.

## جواب سريع عن phpMyAdmin

phpMyAdmin يدير MySQL/MariaDB، فلا يعرض ملف SQLite الخاص بهذا المشروع. افتح الملف بواسطة **DB Browser for SQLite**، من `Open Database` ثم `Browse Data`. [التنزيل الرسمي لـ Windows](https://sqlitebrowser.org/dl/). لا تحتاج اسم مستخدم أو كلمة مرور لمحرك SQLite المحلي؛ حساب `amr` حساب في جدول users داخل التطبيق.

شرح الفتح والتعديل الصحيح لكلمة المرور في [الفصل 05](05-DATABASE.md). لا تضع `123456` نصًا في عمود password؛ المشروع يحفظ Hash ويتحقق منه عند الدخول.

## مثال يربط الفكرة

```text
تضغط حفظ تعديل هاتف العميل
→ maintenance.js يبني النموذج
→ app.js يجمع المدخلات ويرسل POST مع CSRF وrequest_id
→ routes/web.php يوجه إلى CustomerJourneyController::execute
→ middleware يثبت المستخدم والشركة
→ CustomerMaintenance::contact يفحص الملكية والنسخة والحقول
→ Customer Model يكتب في customers ضمن شركة الحساب
→ AuditRecorder يكتب في audit_logs
→ JSON نجاح
→ app.js يعيد جلب البيانات ورسم الملف
```

هذا هو النمط الذي ستراه كثيرًا. الفصل 01 يفصل المصطلحات، والفصل 02 يحدد أسماء الإجراءات لكل قسم.

## حدود هذا الدليل

يغطي ملفات التطبيق التي نكتبها ونعدلها، ومساراتها، ودوال PHP المسماة، ووظائف واجهة المستخدم، وإعدادات التشغيل، وبنية القاعدة كاملة. مكتبات Laravel و Symfony داخل vendor و Leaflet داخل public/vendor تُشرح وظيفتها ولا يعاد شرح كل سطر منها؛ هي مشاريع خارجية كبيرة ولها مراجع رسمية. الفهرس 08 يحدد ملفات الإنتاج والاختبارات والمهاجرات لتستطيع فتح أي تعريف في المحرر.
